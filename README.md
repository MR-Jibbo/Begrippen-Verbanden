# Begrippenlijst Minor Circulaire Economie

Statische website: begrippen, verhaal met voice-over, verbanden en toets.

Zet de bestanden in een GitHub-repository en zet daarna bij Settings > Pages de branch `main` en de map `/ (root)` aan. De site staat daarna op `https://<gebruikersnaam>.github.io/<repository>/`.

Bestanden: `index.html` (de site), `support.js` (de weergave), `voice.mp4` (voice-over met achtergrondmuziek).
